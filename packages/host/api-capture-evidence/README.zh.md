# API Capture 本地证据包

[English](README.md) | 中文

这个 Host 插件为原生 Web 应用保存不可变的 API Capture 证据包。本机接口创建上传事务、接收已声明文件、原子完成目录，并返回可供可编辑 Prompt 引用的绝对路径。

配置项 `root` 管理暂存目录和已完成证据包。已完成证据包不会被修改或自动删除。插件会在启动和创建证据包时删除超过 `stagingTtlMs` 的未完成事务。

创建请求会声明全部文件及其字节数。上传内容流式写入私有临时文件，Host 计算 SHA-256，完成操作写入 `manifest.json` 后再发布目录。文件标识、相对路径、数量和总字节数都会在写入文件系统前校验。

## 模型体验

模型仅会通过引用已完成证据包 `index.md` 路径的 Prompt 间接感知这个插件。这个包本身不增加模型消息或工具定义。

#### KV Cache 影响

这个插件没有直接的 Token 或 KV Cache 影响。后续由用户发送的 Prompt 决定哪些证据路径进入模型历史。

## 已知限制与延期工作

- **仅手动保留策略**：已完成证据包会一直保存到显式 DELETE 请求，用户需要自行管理磁盘占用。
- **仅限本机存储**：证据包路径只在运行当前 Harness Web Host 的电脑上有效。
